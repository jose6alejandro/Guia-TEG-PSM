# Guia-TEG-PSM

Guía interactiva para orientar el desarrollo del Trabajo de Grado del IUPSM. El proyecto reúne información, formatos y recursos útiles para el proceso académico y la presentación final.

Acceso:
https://jose6alejandro.github.io/Guia-TEG-PSM/

## Presentaciones

La hoja de Google debe incluir una columna `anuncio` para alimentar el teletipo que aparece debajo del botón de Cronograma. Si no hay mensajes en esa columna, el portal indica que no hay anuncios publicados.
